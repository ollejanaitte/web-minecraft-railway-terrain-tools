13. 実装概要
    - R2のRepeatedBoxProofRenderer pipelineをそのまま再利用し、
      1m cube (drawCube相当) を「最小3D Rail Segment (drawRailSegment相当)」
      へ置換。
    - 各segment = 左レール + 右レール + 枕木 の3 prism
      (独立3D geometry / setBlockしない / Entity化不要 / texture不要 /
       単色flat color / camera-relative rendering)。
    - Straight RailPath 1本 (20m, R2 fixture再利用) を実距離 s[m] で
      1m間隔にsamplingし、PathSample.frame (RailLocalFrame) に沿って
      segmentを配置 (future Curve/Gradientへの拡張と整合)。
    - normalized progress不使用。実距離のみ。

14. 再利用したR2 pipeline
    StraightGeometry
    → RailPiece
    → RailPath (production API, 再設計なし)
    → RailPath.resolve(s) 実距離sampling
    → PathSample (sample + frame)
    → world-space position
    → camera-relative rendering (GlStateManager.translate(-cam))
    → 反復配置
    ※EntityRenderer pass==0||pass==2 hook / MinecraftServer.onServerTick /
      クライアント記録ワールド名gate / GuiCreateWorld flat強制 もR1/R2流儀を踏襲。

16. Rail Segment geometry仕様
    - segment長: 1.0 m (SEGMENT_LENGTH_M)
    - spacing: 1.0 m (SPACING_M) → segment長 == spacing で隙間・重なりゼロのタイル
    - gauge相当の左右間隔: 1.0 m (GAUGE_M, レール中心間)
    - 左レール: frameの -right 側に gauge/2 オフセット
    - 右レール: frameの +right 側に gauge/2 オフセット
    - 枕木: centerline上 (横方向オフセットなし)

17. rail / sleeper主要寸法
    - rail : 長さ1.0m x 幅0.12m x 高0.18m (steel gray 88,88,100)
    - sleeper: 長さ1.6m x 幅0.12m x 高0.10m (brown 120,82,48)
    - sleeper base: y=4.02 (地面top y=4.0の直上)
    - rail base = sleeper base + sleeper高 = y=4.12 (枕木上に着座)
    - rail top: y=4.30

18. Segment origin contract
    PathSample.position (frame.x/y/z = path centerline点) = segment CENTER。
    レールは frameのright±gauge/2、枕木はcenterline、すべてframeのup方向へ
    鉛直オフセット (RAIL_CENTER_UP_M / SLEEPER_CENTER_UP_M)。
    frame align なのでfuture Curveでもそのまま成立する設計。
