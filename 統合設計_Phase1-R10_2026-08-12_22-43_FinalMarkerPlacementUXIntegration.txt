/railsys3 command contract
-------------------------
通常ワールドで `/railsys3 wand` を実行してマーカーワンドを入手し、Railsys
配置モードを開始する契約を実装。チャットコマンド入力 → ワンド付与 →
配置状態/判定(server-authoritative) → クライアント model / renderer による
表示 → 配置操作へとつなぐ一連のフローをサーバー側契約として定義し、実装した。

Server-authoritative wand
-------------------------
ワンドの付与・配置状態/判定(ItemRailsysMarkerWand)はサーバー権威
(server-authoritative)で管理。クライアントの model / renderer はその
サーバー権威の状態を表示する設計とした。

POS1 / POS2 and marker direction
--------------------------------
配置の始点 POS1・終点 POS2 をクリックで取得し、マーカー矢印で向きを表示。
矢印は POS1/POS2 の両者で「同一データム」(same datum)上に描画され、方向の
視覚的整合性を確保した。

Support-surface Anchor root cause and input-boundary fix
---------------------------------------------------------
Minecraft はクリックしたブロックの bottom Y と当たった面を返す一方、生産
RailPath 契約ではアンカー Y が support surface(床の上面)を指す。この乖離が
根本原因(bottom Y=3 と support-surface Y=4 の差)で、UP 面クリックのブロック
bottom Y を入力境界(RailsysMarkerSelection.selectOnFace)でのみ
support-surface Y(block Y + 1)へ正規化して修正した。正規化は入力境界のみで
実施し、Anchor / Geometry / RailPath / production renderer への +1 workaround
は行っていない。非 UP 面は状態変更前に拒否される。

Arrows / Preview / Confirmed same datum
----------------------------------------
POS1・POS2 のマーカー矢印は同じ support-surface アンカー Y 上に描画される。
プレビューと確定レールは同一の RailPath オブジェクトを promote したもの
(RailsysPlacementController.confirm)で、矢印・プレビュー・確定のいずれも
同一データムに載り、両者で浮き沈みの差が生じず向き・位置が視覚的に一貫した。

Auto Preview
------------
POS2 クリック後、即座にプレビューを自動生成(auto preview)。レールの
経路・距離・向きを確定前に表示し、編集と再確認を可能にした。

Confirm / Cancel / Clear
-----------------------
Confirm: ワンドの Shift+右クリック(Sneak+right-click)で確定。チャットフォール
バック `/railsys3 confirm` も同一経路(RailsysPlacementController.confirm)で動作
し、プレビューが無ければエラーで状態は変化しない。
Cancel: `/railsys3 cancel` はプレビューのみ破棄し、マーカー・編集・cant・確定済
レールを保持する。
Clear: `/railsys3 clear` は一時セッション(マーカー/プレビュー)をリセットし、
確定済みレールとアクティブアセットを保持する。
プレビュー → Confirm の一連の操作が正常に動作した。

User play flow
--------------
1. START ランチャーで通常ワールド(EaglerMarkerPlace)を起動する。
2. チャットで `/railsys3 wand` を入力し、マーカーワンドを入手して
   Railsys 配置モードを開始する。
3. ワンドを選択すると、サーバー権威で管理されるワンド付与・配置状態/判定を
   クライアントの model / renderer が表示する(ワンド・モデル)。
4. 床面(support-surface)で POS1 をクリック → マーカー矢印が表示される。
5. 床面で POS2 をクリック → 同一データム上に矢印が表示され、Auto Preview が
   即座にレールプレビュー(距離 12.08 m / サンプル数 13)を描画する。
6. 必要に応じて R8 編集(handle 10 / rot1(yaw) 20 / pitch 4 / cant 6)で微調整し、
   プレビューを再構築する(asset railsys.prototype_narrow_1000 / narrow_1000)。
7. ワンドの Shift+右クリックで Confirm(フォールバック `/railsys3 confirm`)し、
   プレビューと同一の数値 12.08 m / 13 samples のまま確定する。
8. `/railsys3 cancel` でプレビューのみ破棄(マーカー保持)、`/railsys3 clear` で
   一時セッションをリセット(確定済みレール保持)する。
9. 配置結果をスクリーンショットで確認する(SS-R10-01/02/03)。
