17. R11-E Signal / Crossing / Connector

      block-section wiring (last-input-wins); converter network (RS<->Signal,
      +1, -1).
    - Rail core carries signal/occupancy (getSignal/setSignal(int),
      isCollidedTrain) — key rail-side hook.
    - Crossing gate = MachineType.Gate (barMoveCount/lightCount/onActivate);
      sound 0/1 + range 32. Connector = Connection {isRoot,x,y,z,type,
      wireName} NBT; ModelConnector JSON (Relay/DSS/wirePos).
    - Railsys Phase 1: add signalState/occupied + connection data + stable rail
      id (R-P1); full signal/crossing logic DEFER Phase 2.
    - (RTM_SIGNAL_CROSSING_CONNECTOR.md)
