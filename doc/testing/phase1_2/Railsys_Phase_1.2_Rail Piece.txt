RailPiece contract
------------------
Stable int pieceId = geometry.pieceId() (no duplicated id). Endpoint pose is
derived from geometry at s=0 / s=length (single source of truth). Zero /
non-finite length rejected. Optional metadata hook. Value-based endpoint
identity for future persistence. See RAIL_PIECE_CONTRACT.md.

RailEndpoint
------------
START at geometry s=0, END at s=length. Native tangent/yaw/pitch always along
geometry start->end. Reverse traversal negates tangent for travel use.

RailConnection / validation
---------------------------
Position tolerance 1e-4 m; tangent tolerance 0.5 deg (0 or 180 deg both valid
for a physical join; a PATH additionally requires same-direction continuity).
Null / self / duplicate / unknown-piece / misaligned connections rejected with
reason + numeric errors. Silent gaps forbidden.

RailPath / cumulative distance / resolver
-----------------------------------------
Ordered entries with cumulative prefix lengths; total = sum of piece lengths
(exact: 80+65+100 = 245.0). resolve(globalM) binary-searches piece start
offsets (upper-bound starts[i+1]>=s) then maps to local distance. Returns
PathSample with piece id, index, local distance, traversal direction, native
sample + frame and travel-adjusted heading.

Boundary ownership rule (frozen Phase 0.6)
------------------------------------------
Internal boundary owned by the EARLIER piece (exit sample at its end); final
boundary owned by the last piece. Implemented exactly via the binary search
convention; NO magic epsilon in the resolver (B±δ used only as test input).

Reverse traversal
-----------------
reverse() returns same pieces in reverse order, each direction -1. Local
distance = globalEnd - g; travel tangent = -native; travel yaw = native+180
(wrapped); travel pitch = -native. Forward/reverse consistency: same world
position (8.6e-14 m worst) with opposite travel tangents.

Error / clamp policy
--------------------
s<0 -> clamp 0; s>total -> clamp total; NaN/Inf -> IllegalStateException;
empty path / zero-length piece / disconnected entries -> rejected at
construction. Unexpected exceptions counted: 0.

Lightweight RailNetwork
-----------------------
addPiece/getPiece/removePiece, connect/disconnect, adjacency lookup,
network-wide validate. NO A*, NO switch routing, NO persistence. Multiple
connections per endpoint allowed (future switch branch compatibility).
