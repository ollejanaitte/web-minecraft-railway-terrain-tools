# ADR-003: Distance-based Formation
Status: Accepted (Phase -1)
## Context
v1 follower = leader.progress +/- offset with modulo wrap -> follower
teleports at segment transitions (documented bug). RTM uses bogie anchors
and distance [R-I].
## Decision
Leader advances a continuous path distance; follower k at
leaderDistance - k*carSpacing, resolved by walking backward across path
entries. segment progress is only a lookup key, never formation authority.
## Alternatives
- v1 progress-based - rejected (bug).
- Per-car independent progress - rejected (spacing drift).
## Pros
Fixes teleport/disappearance; meter-accurate spacing; supports loops,
switches, reverse, long trains.
## Cons
Requires arc-length + path resolver (Phase 1).
## Risks
Resolver cost at scale (mitigated by caching/spatial index).
## Consequences
Primary acceptance criterion (no teleport, spacing kept) enabled.
