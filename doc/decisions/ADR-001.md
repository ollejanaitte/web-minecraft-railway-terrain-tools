# ADR-001: Scale and Units
Status: Accepted (Phase -1)
## Context
RTM is 1:1 real scale (1 block = 1 m) [CONFIRMED-RTM]. Current /railsys is
block-progress based. To support 10-20m vehicles and RTM parity, units must
be consistent.
## Decision
Adopt 1 block = 1 metre everywhere. Speeds in m/tick (blocks/tick);
accelerations in m/tick^2; conversion km/h / 72 = m/tick [R-I].
## Alternatives
- 1 unit = 1/16 block (RTM rail height uses 1/16 block for heights, but
  positions are metres) - rejected: mixed units cause errors.
- Abstract "unitless" - rejected: no RTM parity.
## Pros
Simple, RTM-consistent, no conversion bugs for car/rail sizes.
## Cons
Large vehicles span multiple chunks (handled in perf design).
## Risks
None significant.
## Consequences
All geometry/train math uses metres; UI may display km/h.
