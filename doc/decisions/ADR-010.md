# ADR-010: Web Model Format
Status: Accepted (Phase -1)
## Context
RTM uses OBJ/MQO runtime [R-I]. Browser/TeaVM runtime parse is slow and
memory-heavy.
## Decision
v2 native runtime format (rv2m: JSON mesh with parts/materials/uv/normals,
cacheable by hash). OBJ/MQO import via an OFFLINE converter (content-
converter). Optional debug OBJ/MQO parse for tooling only.
## Alternatives
- Runtime OBJ parse - rejected (perf/memory).
- Runtime MQO parse - rejected (parser complexity/perf).
## Pros
Fast load, small, cacheable; import pipeline keeps RTM-compatible assets
(license-gated).
## Cons
Needs converter tooling (Phase 8).
## Risks
Converter fidelity (round-trip tests).
## Consequences
Content pipeline: pack assets -> rv2m; client loads rv2m only.
