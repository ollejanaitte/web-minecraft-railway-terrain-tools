# ADR-011: Switch as Real Geometry
Status: Accepted (Phase -1)
## Context
v1 switch = node->segment id map. RTM switch = rail piece with branch
geometry and state [R-I].
## Decision
A SWITCH piece exposes branch geometries; active branch selected by state;
followers follow the same active branch (shared path). Not merely a
"next segment id".
## Alternatives
- v1 map - rejected (no geometry, followers can diverge).
## Pros
Correct routing; formation consistency; interlocking support.
## Cons
More geometry work (Phase 3).
## Risks
Branch continuity (tested).
## Consequences
Route/switch locking in Phase 5 works on piece state.
