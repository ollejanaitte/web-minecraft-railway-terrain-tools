# ADR-009: Legacy Migration
Status: Accepted (Phase -1)
## Context
v1 /railsys is a prototype; replacing it abruptly breaks saved worlds and
existing dev work.
## Decision
Staged migration: freeze v1; build v2 in new packages; V1Adapter translates
old entity/commands to v2; data migration v1->v2 with backup; deprecate v1
in Phase 11.
## Alternatives
- Big-bang rewrite - rejected (data loss, risk).
## Pros
No breakage; rollback safe.
## Cons
Dual systems temporarily (managed in Phase 0-10).
## Risks
Adapter bugs (soak gated).
## Consequences
v1 preserved as dev asset and test baseline; v2 adopted gradually.
