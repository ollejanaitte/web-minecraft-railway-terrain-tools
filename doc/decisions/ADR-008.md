# ADR-008: Persistence Schema
Status: Accepted (Phase -1)
## Context
v1 saves graph in WorldSavedData "rail_system". v2 must persist pieces,
formations, signals, stations, crossings, catenary, object state, content
ids, with migration.
## Decision
WorldRailData schema v2 under key "rail_system" (or "rail_system_v2"):
schemaVersion, pieces, nodes, switches, signals, stations, crossings,
catenary, formations (FormationRecord with defIds + path + state), objects.
Arc tables recomputed on load; content by defId; v1 backup key retained.
## Alternatives
- Store everything in entities - rejected (blocks are chunk data; logic
  separate).
## Pros
Versioned; migration-friendly; resumable formations.
## Cons
Migration complexity (managed).
## Risks
Schema drift (version field + compat).
## Consequences
Formations resume after reload at exact positions.
