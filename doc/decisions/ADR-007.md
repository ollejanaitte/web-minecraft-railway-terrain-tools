# ADR-007: Multiplayer Authority
Status: Accepted (Phase -1)
## Context
RTM is Forge client/server; v2 targets Eaglercraft. Current v1 relies on
shared-JVM static graph and DataWatcher.
## Decision
Server authoritative for all railway physics/state. Client is a read-only
mirror with interpolation; client sends only input commands. RailwaySync
packets (snapshot + delta + pose batches + state). No client prediction in
v1.0.
## Alternatives
- Client-side prediction - later extension behind this ADR.
## Pros
Deterministic; secure; simple client.
## Cons
Input latency for driving (acceptable; interpolation smooths).
## Risks
Bandwidth (budgeted); sync complexity (Phase 10).
## Consequences
Client never owns rail math; v1 DataWatcher migrated to RailwaySync.
