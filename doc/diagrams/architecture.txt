Data flow (server tick):
  inputs -> TrainController -> leaderPathDistance += dir*speed*dt
  -> path.resolve() -> sampleByDistance per bogie -> TrainPose
  -> followers walk-back -> signals/occupancy (head/tail)
  -> dirty flags -> sync build -> packets -> client mirror -> render
