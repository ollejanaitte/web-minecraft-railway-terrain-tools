20. START_WEB_MINECRAFT.sh仕様
====================================================================
repository root に配置。正式な単一起動入口。
- 実行権限付与済み（-rwxrwxr-x）
- スクリプト位置から repository root を自動取得（実行場所非依存）
- JAVA_HOME default = /usr/lib/jvm/java-17-openjdk-amd64
- クライアント成果物（offline HTML）が無い/古い場合は
  ./gradlew makeMainOfflineDownload を自動実行
- 起動後5秒で即死検知し、ログ末尾30行を表示して画面を閉じない
- 通常プレイ専用プロファイル runtime/profiles/game を使用
  （検証プロファイルと完全分離）
- 二重起動は既存インスタンス検知で回避（stopサブコマンドあり）
- DISPLAYあり: GUIウィンドウモード（ChromeデフォルトGPU設定）
  ※ --use-gl=angle --use-angle=vulkan はGUIでEGL失敗を確認し不採用
- DISPLAYなし: headless+CDP（--remote-debugging-port, 既定9222）
  port競合時は意味のあるエラーを表示
- ローカルHTTPサーバー不要（file:// offline HTML を使用）
- 通常ユーザーのChromeをkillしない（専用profileのみ管理）

21. .desktop launcher有無
  有り。START_WEB_MINECRAFT.desktop を repository root に作成し、
